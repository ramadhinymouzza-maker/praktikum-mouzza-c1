# Praktikum C - Sistem Penilaian Kelulusan
**Nama: Mouzza Ramadhiny**

## Deskripsi Tugas
Program menentukan status kelulusan berdasarkan Nilai Akhir dan Kehadiran.

Rumus: Nilai Akhir = (0.20 * Tugas) + (0.30 * UTS) + (0.50 * UAS)

- LULUS DENGAN PREDIKAT: Nilai >=85, Kehadiran >=90, Nilai Genap
- LULUS: Nilai >=75, Kehadiran >=80
- BELUM LULUS: Selain itu
